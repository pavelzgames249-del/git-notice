git init - инициализация, создание нового репеозиторя (первращение папки с кодом в гит проект).
git status - показывает твой текущий статус.
git add <имя файла> - добовляет в систему гит твой текстовый файл и изменения. 
git add . - добовляет все новые файлы и изменения. 
git commit -m "Коментарий" - делает постоянную точку сохрнения (чекпоинт) если код сломается то можно будет вернуться в один клик к этой точке.
git show - берет самый последний коммит и подробно расписывает все мето данные (автор, дата, хеш ID.) и пишет что изменилось в тексте подписывая строки "+" и "-" что изменялось и удолялось и какие строки были добавлены.
git branc - показывает в какой ты ветке находишся.
git branch <имя ветки> - создает новую изолированую ветку (поралельное пространство кода).
git remote add origin <ссылка скопированая с создонового репеозиторя GitHub> - привязывает твой локальный репозиторий на компьютере к удоленному (пустому) репозиторию в облаке гитхаб.
git push -u origin master - отправляет код на гитхаб в первый раз. она не просто загружает коммиты из ветки master но и флагом -u склеивает локальную ветку с удоленной, что бы адльше можно было писать короткую команду git push.
git push - берет все новые сделаные локальные коммиты (сохранения) и закачивает их на гит хаб в уже связаную ветку.
git log - выводит полную историю всех коммитов (сохранений) которые были сделаны в репозитории, начиная с самого первого дня (дату, пользователя, уникалтный хэш ID коммита, коментарий.).
git log --oneline - сокращенный, выводит только (хэш ID, и коментарий).
git diff - показывает точную разницу между файлами если git status просто говорит: "файл изменен" то git diff показывает какие именно буквы и строки внутри файла я перписал с последнего момента сохранения.
git clone <ссылка моего репозиторя GitHub> - там после махинации создания папки и открытия консоли гит пишешь эту команду и у меня склонируется эта папка ко мне на комп.
